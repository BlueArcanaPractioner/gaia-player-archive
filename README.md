# Gaia Player Archive

A static, mobile-friendly archive for the Lower March campaign.

## Repository layout

- `index.html` — the self-contained player archive and future GitHub Pages entry point.
- `.nojekyll` — tells GitHub Pages to serve the repository as plain static files.

## Connect to GitHub Pages later

Open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

Once Pages is enabled, the archive should be available at:

https://bluearcanapractioner.github.io/gaia-player-archive/

The archive has no build step or external dependencies.
